# VOICE Radar

Ловит тренды для квотов и опросов в Social Camp. Каждые ~5 минут GitHub Actions запускает один тик:
собирает источники, находит то, что разгоняется, Claude отсекает шум, склеивает дубли и пишет
черновик QT и вопрос для опроса. Громкое уходит пушем в Telegram, всё остальное лежит в ленте
с окнами 1ч / 6ч / 12ч / сутки / неделя.

## Источники

| Что | Откуда | Цена |
|---|---|---|
| Твиты ~120 аккаунтов (крипто-новости, Solana, KOL, ончейн, AI) | X List через Sorsa `/list-tweets` | Sorsa |
| Новостные «пожарные шланги» и вирусные аккаунты, только залетевшие посты | Sorsa search с `min_faves` | Sorsa |
| Вирусные крипто-твиты от кого угодно | Sorsa search по темам | Sorsa |
| Тренды X: мир, США, UK | trends24.in | бесплатно |
| Рынки Polymarket: новые в топе, резкие движения | gamma API | бесплатно |
| Тренды поиска CoinGecko | API | бесплатно |
| Новости: CoinDesk, The Block, Decrypt, Google News, BBC, Guardian, TechCrunch, Verge | RSS | бесплатно |

Список аккаунтов: `watchlist.json`. Пороги, частоты, окна: `config.json`.

## Как понимает, что «залетело»

- **Твит.** Сравнивает реакции с обычными постами этого автора (медиана последних 30). ×3 и выше = кандидат.
  Пока у автора нет истории, меряет реакции на 1k подписчиков.
- **Волна.** Одно имя или тикер за 3 часа у 3+ разных аккаунтов, и это ×3 к фону за неделю.
- **Тренд X.** Ворвался в топ-15 страны, которого не было 6 часов, или прыгнул на 10+ мест в топ-10.
- **Polymarket.** Новый в топ-20 по объёму за сутки или цена главного рынка сдвинулась на 15+ п.п. Спорт выкинут.
- **Новости.** Одну историю пишут 3+ издания, или крипто-срочное (hack, ETF, SEC, listing...).

Каждый кандидат оценивает Claude: релевантность для CT 0-10, срочность, можно ли из этого сделать опрос,
черновики. Пуш уходит при релевантности 7+ (или 6+ и срочно), не больше 6 в час. Сводка в 10:00 и 19:00 МСК.

## Секреты (GitHub → Settings → Secrets and variables → Actions)

| Имя | Что |
|---|---|
| `SORSA_API_KEY` | ключ Sorsa. Без него X-слой выключен, остаются бесплатные источники |
| `ANTHROPIC_API_KEY` | ключ Claude. Без него нет черновиков, релевантность по ключевым словам |
| `TELEGRAM_BOT_TOKEN` | @voicefunreports_bot |
| `TELEGRAM_CHAT_IDS` | куда слать, через запятую (группа с Пашей) |
| переменная `RADAR_LIST_ID` | id публичного X List с аккаунтами из `watchlist.json` |
| переменная `RADAR_FEED_URL` | адрес ленты, для кнопки в пушах |

Бюджет Sorsa: `daily_budget` в `config.json` (320 в день ≈ 9.6k в месяц, влезает в тариф Starter).

## Локально

```bash
python -m radar.run --data data --dry --force     # один тик, алерты в консоль
python -m unittest discover -s tests -t .
python -m radar.verify_watchlist                   # проверить хэндлы (нужен SORSA_API_KEY)
python -m radar.tg_chats                           # id чатов бота (нужен TELEGRAM_BOT_TOKEN)
```

Память радара (`state.json`, `feed.json`) живёт в ветке `data`, каждый тик перезаписывает её одним коммитом.
